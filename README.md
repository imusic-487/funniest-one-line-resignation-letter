## The entry

> I have fired every minute since March, never once been thanked, and today I resign — my replacement can enjoy the 3 a.m. pages.

## How it works

`main.py` writes that single line (127 characters) to `/output/entry.txt`. It checks first that the entry is one line of 1–140 characters, so the gate always passes.
